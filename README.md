# Prompt Engineering Experiments 🚀

### Valentius Kryptix – AI Internship | Task AI-2

## 📌 Project Overview

This repository documents three practical prompt engineering experiments conducted using **Google AI Studio and Gemini 3.8 Flash**.

The objective is to understand how different prompting techniques influence the accuracy, consistency, and structure of Large Language Model (LLM) responses.

## 🎯 Experiments

### 1. Zero-shot vs Few-shot Prompting
- Task: Customer review sentiment classification.
- Compared prompts with and without examples.
- Both approaches classified the review as Positive.

### 2. Chain-of-Thought Prompting
- Task: Multi-step shopping discount calculation.
- Compared direct prompting with step-by-step prompting.
- Both approaches produced the correct answer: ₹1,808.
- Step-by-step prompting provided a more transparent calculation.

### 3. Structured JSON Output
- Task: Extract names, dates, and amounts from text.
- Tested five different input examples.
- Used explicit JSON keys, data types, and formatting rules.
- Result: **5/5 records passed (100%).**
